## 🚀 Featured Projects

### 1. 🤖 Autonomous UI Testing Agent

**AI-powered browser testing and workflow automation**

An AI-assisted testing agent that reads a mock issue, generates a test plan, executes browser actions, checks acceptance criteria, and prepares test reports with supporting evidence.

**Tech Stack:** Python · OpenAI API · Playwright · Pytest · JSON

**Workflow:**
1. Read the issue from `mock_issue.json`.
2. Generate a structured test plan using an LLM.
3. Execute browser actions on a demo e-commerce website.
4. Validate login, product addition, cart verification, and product removal.
5. Generate test documentation, logs, screenshots, and a final report.

**Target Website:** [SauceDemo](https://www.saucedemo.com/)

**Run Command:**
```bash
python -m src.main
```

**Deliverables:**
- `TEST_PLAN.md`
- `SCENARIOS.md`
- `README.md`
- Screenshots and execution logs
- Final test report

**Current Status:** Code prepared; end-to-end execution pending. GitHub webhook integration is not implemented.
